# LifeXP ⚔️

> **An Immersive Real-Life RPG Experience** — Level up your real life with gamified quests, skill trees, achievements, character progression, and leaderboards.

---

## 🌟 Features

- 🎮 **Gamified Quests & Habits**: Create daily quests, epic challenges, and recurring habits with XP, gold, and stat rewards.
- 🧙‍♂️ **Character Progression**: Track your stats (Strength, Intellect, Agility, Vitality, Charisma), current level, and rank titles.
- 🌳 **Interactive Skill Tree**: Unlock and upgrade skills across multiple discipline trees using your hard-earned skill points.
- 🏆 **Achievements & Badges**: Unlock badges, milestone rewards, and titles as you accomplish real-world goals.
- 📊 **Dynamic Dashboard & Analytics**: Visual activity heatmaps, streak tracking, and stat distribution radars.
- 🥇 **Leaderboards**: Compete against friends and global adventurers across weekly, monthly, and all-time rankings.

---

## 🚀 Tech Stack

- **Frontend**: React 19, Vite, Lucide Icons, Vanilla CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB / Mongoose (with MongoDB Memory Server for instant local development)

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/1996udaypat-ai/lifexp.git
   cd lifexp
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. (Optional) Seed the database:
   ```bash
   npm run seed
   ```

4. Run the development server (client & backend concurrently):
   ```bash
   npm run dev
   ```

5. Open [http://localhost:5173](http://localhost:5173) in your browser.
